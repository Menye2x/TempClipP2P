Temporary Clipboard

Live text sync between paired devices. Clipboard content exists only in browser RAM.
Starting session…
How this app works: one device starts a live temporary session, then another device joins by scanning a short-lived pairing QR. After pairing, both devices can send and receive text in either direction through a WebRTC peer connection. Clipboard text exists only in browser RAM, so refreshing or closing the app clears the temporary data. No clipboard text is intentionally stored in a database or cloud storage.
